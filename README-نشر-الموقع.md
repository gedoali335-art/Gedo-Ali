# موقع حضانة ونادي جدو علي — دليل النشر المجاني

الموقع ملفات ثابتة (HTML / CSS / JS) ويعمل بلا سيرفر مدفوع، وتكلفة تشغيله **صفر**. يتكوّن من ثلاثة أجزاء مجانية:
1. **الموقع نفسه** (استضافة GitHub Pages) — الخطوة 1.
2. **استلام الاستمارات** على البريد (FormSubmit) — الخطوة 2.
3. **حجز المواعيد** (Google Sheet + Apps Script) — الخطوة 3.

استخدموا **نفس البريد gedoali335@gmail.com** في كل الحسابات ليكون هو المسؤول عن أي تعديل لاحقًا.

---

## 1) نشر الموقع على GitHub Pages
1. افتح حسابًا على github.com بالبريد gedoali335@gmail.com.
2. **New repository** باسم `gedoali` ← اجعله **Public**.
3. **uploading an existing file** ← ارفع محتويات المجلد (index.html + مجلدات css و js و images + الملف `.nojekyll`) ← **Commit**.
   (مجلد `booking-backend` اختياري للرفع؛ مكانه الأساسي في الخطوة 3.)
4. **Settings ← Pages**: Branch = `main` والمجلد `/ (root)` ← **Save**.
5. بعد دقيقة يظهر الرابط: `https://اسم-الحساب.github.io/gedoali/`

**بدائل مجانية بنفس الملفات:** Cloudflare Pages (Upload assets) أو Netlify Drop (app.netlify.com/drop). إن لم يفتح أحدها عند بعض شركات الاتصالات جرّب بديلًا، أو اربط دومين خاص بنفس الاستضافة المجانية.

## 2) تفعيل استلام الاستمارات (مرة واحدة)
1. بعد نشر الموقع املأ الاستمارة بنفسك وأرسلها كتجربة.
2. ستصل رسالة من FormSubmit بعنوان **Activate Form** على البريد ← اضغط التفعيل.
3. بعدها تصل كل استمارة جدولًا منظمًا (تفقد **Spam** أول مرة).

## 3) تفعيل حجز المواعيد (مرة واحدة — حوالي 10 دقائق)
قواعد الحجز: مقابلات من **9:00 ص إلى 12:00 ظ** (أوقات البدء: 9:00 – 9:40 – 10:20 – 11:00 – 11:40)، بحد أقصى **5 مقابلات في اليوم**، ويُغلق اليوم تلقائيًا عند اكتمال الخمس. الأيام المتاحة: الأحد إلى الخميس، من الغد وحتى 75 يومًا.

لأن الموقع ثابت، تُحفظ الحجوزات في جدول Google خاص بكم:
1. من حساب gedoali335@gmail.com افتح **sheets.google.com** وأنشئ جدولًا فارغًا باسم «حجوزات جدو علي».
2. من القائمة: **الإضافات (Extensions) ← Apps Script**.
3. احذف الكود الموجود والصق محتوى الملف **`booking-backend/Code.gs`** كاملًا ثم **Save**.
4. اضغط **Deploy ← New deployment** ← النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy** ووافق على الصلاحيات (قد تظهر شاشة تحذير: **Advanced ← Go to project** — طبيعي لأن السكربت لكم).
5. انسخ **Web app URL** (ينتهي بـ `/exec`).
6. افتح `js/main.js` وألصقه بين علامتي التنصيص هنا:
   ```js
   bookingApi: 'https://script.google.com/macros/s/XXXX/exec'
   ```
   ثم ارفع الملف المعدّل على GitHub.

**ما لم تضعوا الرابط:** تظهر في آخر خطوة بالاستمارة رسالة «الحجز الإلكتروني غير مفعّل» وتبقى الاستمارة تعمل عادي.

### إدارة الحجوزات
- كل حجز يُسجَّل في ورقة **«الحجوزات»** (بيانات الموعد فقط) ويصلكم تنبيه على البريد.
- الاستمارة **كاملة** تُحفظ أيضًا في ورقة **«الاستمارات»** (عمود لكل سؤال وصف لكل طفل)، نسخة احتياطية بجانب البريد.
- بعد أي تعديل على `Code.gs`: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** (الرابط لا يتغير).
- **إلغاء حجز / فتح الموعد:** غيّروا الخانة في عمود «الحالة» إلى `ملغي` فيُفتح الموعد فورًا.
- **إغلاق يوم (إجازة):** ورقة **«أيام مغلقة»** ← اكتبوا التاريخ بصيغة `2026-11-05` في العمود الأول.
- **تغيير العدد أو الساعات:** أول `Code.gs` (`MAX_PER_DAY` و`SLOTS`)، ثم **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** (الرابط لا يتغير). التقويم يقرأ الساعات من السكربت تلقائيًا.
- كل ولي أمر له حجز قائم واحد برقم هاتفه (حتى لا تُحجز الأيام كلها من شخص واحد).

## 4) التعديل لاحقًا
- **النصوص:** `index.html` من GitHub (أيقونة القلم) ثم Commit.
- **الألوان:** أول `css/style.css` (`:root`).
- **الصور:** ارفع الصورة في `images` وأضف `<figure>` في قسم المعرض.
- **بريد الاستمارات والرابط:** أول `js/main.js` (`CONFIG`).
- **الأرقام:** ابحث عن `01000837504` و`034595999` في `index.html`.
- **الخريطة وفيسبوك:** ابحث في `index.html` عن `google.com/maps` و`facebook.com`.
